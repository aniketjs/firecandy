# Firecandy!

A customized chrome addon I made to replace the boring old chrome homepage.

## Installation

- [Download](https://github.com/aniketjs/firecandy/archive/refs/heads/main.zip) this repository.
- Extract the zip file anywhere on your hard drive.
- Open chrome then go to `Settings > Extensions`.
- Turn on `Developer mode` in the top right corner.
- Now click on `Load unpacked`
- Browse to where you unpacked the repo and select it.
- Voila! (Don't forget to keep the settings when prompted).
